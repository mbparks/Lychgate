# LYCHGATE v5.3.0: The Instrument Pass

LYCHGATE v5.3.0 is a release about attention. Nothing new has been added to the haunted map. Instead, the instrument around it has been rebuilt so the existing systems are easier to see, easier to work, and easier to carry into the field.

The application had grown from a map and Threshold workbench into a large offline practice with Expeditions, Passage Stones, cryptographic identity, regional authoring, a Lore Cabinet, and branching Scenarios. The systems belonged together, but the interface had accumulated too many equally weighted boxes and too many controls that looked equally important. v5.3.0 gives that complexity a stronger hierarchy.

The station rail now separates Field Work, Authoring, and System functions. Numbered stations replace decorative symbols that were difficult to scan. Display type, interface text, and technical readouts each have their own role. Brass is reserved for actions that matter. Secondary controls recede. Dense registers are ruled like field records rather than repeated as stacks of cards.

Field received the most attention. The local survey is now the dominant object on the screen, with position controls held close but visually quieter. Nearby Thresholds read as a register. On a phone, the same system becomes a compact single-column field instrument with a slide-out station drawer rather than a squeezed desktop layout.

The pass also tightened behavior. Changing stations returns the workspace to its beginning. Escape gets you out of Walk Mode or closes the mobile drawer. Collapsed stations retain useful hover labels. Touch targets remain at least 44 pixels even where the visuals are compact. High Contrast, visible focus, and Reduced Motion remain part of the core interface rather than optional polish.

The aesthetic is still LYCHGATE: bone, iron, tallow, old survey lines, and a little brass. No web font or decorative image download was introduced. The entire redesign remains local CSS and system typography, so the game still works with the radio off.

This is not a new chapter of the rules. It is the point where the instrument finally looks and behaves like one coherent thing.
